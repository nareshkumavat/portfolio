## ⚡ Features

- **Terminal Boot Sequence**: Custom retro-futuristic loading sequence and system status check.
- **Interactive Particle Canvas**: Constellation particle field with cursor interaction.
- **Live Profile JSON Viewer**: Clean data inspector displaying core competencies and status.
- **Projects Showcase**: Interactive spotlight and 3D tilt cards featuring projects like **ClientPDF** and **Trajectio**.
- **Skill Matrices**: Grouped technology stacks across AI/ML, Data Systems, and Full-Stack Engineering.
- **Responsive & Accessible**: Fully responsive layout with `prefers-reduced-motion` compliance.

## 🚀 Getting Started

No build step or external dependencies required. Simply open `index.html` in your browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve
```

Then visit `http://localhost:3000` in your web browser.

## 🌐 Deploy to GitHub Pages

1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
